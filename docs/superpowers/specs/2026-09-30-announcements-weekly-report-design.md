# Church：公告欄與同工週報

## 目標

1. **公告欄**：對所有訪客公開，列出接下來要公告的事項（例如「10/12 秋季退修會報名截止」），到期自動下架。
2. **同工週報**：每週一份，內部查閱，以密碼（初始 `110550`）進入；內容為自由格式文字加附件（PDF、Word、圖片）。

兩者都在現有後台（`/admin`）編輯。

## 放在哪裡

| 功能 | 位置 | 入口 |
| --- | --- | --- |
| 公告欄摘要 | 首頁 Hero 上的浮動小卡：桌面在右側、手機在下方，可關閉 | 首頁 |
| 公告欄全文 | 新頁面 `/announcements` | 首頁「查看全部公告 →」、「聯絡我們」選單 |
| 同工週報 | 新頁面 `/weekly`（不在主選單） | 頁尾小連結「同工週報」、直接分享網址 |
| 編輯 | 後台側欄「主日直播」之後新增「公告欄」「同工週報」 | `/admin` |

## 資料與儲存

### 公告 `announcements`（D1）

| 欄位 | 說明 |
| --- | --- |
| `id` | TEXT 主鍵 |
| `title` | 標題，必填 |
| `body_html` | 內容（富文字，沿用後台現有編輯器；顯示方式與網站文字相同，用 `toDisplayHtml`。只有登入的管理者能寫入） |
| `event_date` | 活動日期 `YYYY-MM-DD`，可空 |
| `show_until` | 顯示到 `YYYY-MM-DD`，必填 |
| `created_by`、`created_at`、`updated_at` | |

公開讀取不碰 D1：網站快照（KV `site:v2`）新增 `announcements` 欄位，放 `show_until >= 建置當天` 的公告。首頁與 `/announcements` 從 bootstrap 取得。

- **到期以前端判斷**：頁面依「今天（教會所在的 America/Los_Angeles）」過濾 `show_until < 今天` 的公告，所以不必等快照重建，當天就會下架。
- **排序**：`event_date`（沒有就用 `show_until`）由近到遠。
- 公告的新增、修改、刪除都觸發 `rebuildSnapshots`（加入 `shouldRebuildSnapshot` 的路由清單）。

### 週報 `weekly_reports`（D1）

| 欄位 | 說明 |
| --- | --- |
| `id` | TEXT 主鍵 |
| `week_of` | 該週週日 `YYYY-MM-DD`，**UNIQUE**（每週只一份） |
| `title` | 標題 |
| `body_html` | 內容（富文字） |
| `attachments` | JSON 陣列 `[{ key, name, size, type }]`，有順序 |
| `created_by`、`created_at`、`updated_at` | |

附件存 R2（沿用現有 bucket），key 前綴 `weekly/<reportId>/`。**不經過** 公開的 `/api/images/` 路由；只能透過需要通行證的週報路由下載。

- 允許類型：PDF、Word（`.doc`、`.docx`）、圖片；單檔上限 20 MB。
- 刪除週報或移除附件時一併刪除 R2 物件。

### 週報密碼

- 存在 `settings`，只存雜湊：`{ salt, hash }`，雜湊方式沿用 `hashPassword`（`sha256(salt:password)`）。
- 初始密碼 `110550`：由 migration 寫入其雜湊（在 migration 中預先算好的 salt 與 hash，不在程式碼裡放明文）。
- 只有 owner 能修改；修改後舊通行證全部失效（見下）。

## 存取控制

- `POST /api/weekly/unlock { password }`：比對雜湊，正確就設定 `weekly_access` cookie（HttpOnly、Secure、SameSite=Lax、30 天）。
  - cookie 值為 `<到期時間>.<HMAC(密碼雜湊, 到期時間)>`：以密碼雜湊當金鑰，改密碼即讓所有舊 cookie 驗證失敗，不必另外記錄。
  - 失敗次數限制：同一 IP 每分鐘最多 5 次，超過回 429（計數放 KV，1 分鐘過期）。
- `GET /api/weekly`（清單，不含內文）、`GET /api/weekly/:id`（含內文與附件清單）、`GET /api/weekly/files/<key>`（下載附件）：**全部在伺服器驗證 `weekly_access`**，沒有或過期回 401。登入中的後台管理者（admin session）也可直接讀取。
- `POST /api/weekly/lock`：清除 cookie（「鎖定」按鈕）。
- `/weekly` 頁面加上 `<meta name="robots" content="noindex">`，週報 API 回應加 `Cache-Control: private, no-store`。

> 與現有相簿密碼的差異：相簿的 `/api/photos/unlock` 只回答密碼對錯，照片清單本身不需密碼即可取得。週報是內部資料，所以資料端點本身必須驗證，不能只擋畫面。

## 前台頁面

### 首頁公告小卡（浮於 Hero 上）

不另佔版面，疊在 Hero 圖片上，不遮住中間的主標題與按鈕。

- **桌面**：Hero 右側、垂直置中的半透明深色小卡，寬約 320px。
  - 標題列「最新公告」與右上角 ×。
  - 最多 3 則未過期公告，每則一行：日期徽章（如「10/12 週日」）＋標題（過長截斷）；點一則到 `/announcements#<id>`。
  - 最下方「查看全部 →」。
- **手機**：Hero 下緣、左右留邊的精簡橫條。
  - 只顯示最近一則（日期＋標題），右側「另有 N 則」與 ×；點橫條到 `/announcements`。
- **關閉**：按 × 後在這台裝置上隱藏（localStorage 記住當下看到的公告 id）。之後只要出現**新的**公告就再次顯示；只是舊公告到期不會讓它重新出現。
- 沒有未過期公告時不顯示。
- 出現時淡入，不擋載入；關閉後 `/announcements` 與「聯絡我們」選單的入口照舊可用。

### `/announcements`

- 與其他頁面相同的頁首橫幅；列出所有未過期公告的完整內容，由近到遠。
- 網址帶 `#<id>` 時捲動到該則並短暫標示。
- 沒有公告時顯示「目前沒有新公告」。

### `/weekly`

- **未解鎖**：密碼輸入框與「進入」，樣式比照相簿密碼頁；錯誤顯示「密碼不正確」，被限速時顯示「嘗試次數過多，請稍後再試」。
- **已解鎖**：
  - 左欄（手機在上方）：週次清單「2026/10/4 週 · 標題」，新到舊；預設開啟最新一週。
  - 右欄：標題、週次、內文、附件清單（檔名、大小、下載；PDF 在瀏覽器開啟，Word 直接下載）。
  - 右上「鎖定」按鈕。
- 沒有任何週報時顯示「尚無週報」。

## 後台

新增兩個區塊，同工（contributor）與擁有者（owner）都能使用；「週報密碼」僅 owner。（教會網站目前沒有操作日誌，這次不另建。）

### 公告欄

- 清單分「顯示中」「已過期」兩組；每則顯示標題、活動日期、顯示到。
- 操作：編輯、刪除、**複製**（以該則為範本開新公告，日期清空）。
- 表單：標題（必填）、活動日期（選填）、顯示到（必填；預設為活動日期，沒有則今天起 14 天）、內容（富文字）。
- 儲存後約一分鐘內前台更新（KV 最終一致）；後台畫面立即以本地狀態反映。

### 同工週報

- 週次清單新到舊；「新增本週週報」預填本週週日。該週已有週報時改為開啟既有那份。
- 表單：週次（只能選週日）、標題、內容（富文字）、附件（多檔上傳、可刪除、可調整順序）。
- 「週報密碼」設定（owner）：新密碼輸入兩次；儲存後所有裝置需重新輸入。

## 錯誤處理

| 情況 | 行為 |
| --- | --- |
| 快照中沒有 `announcements`（舊快照） | 當成沒有公告；下次重建即補上 |
| 週報 API 未帶或帶了過期 cookie | 401，前端回到密碼畫面 |
| 附件上傳失敗、超過 20 MB 或類型不符 | 表單上顯示原因，不存入 |
| 同一週重複建立 | 伺服器以 UNIQUE 擋下回 409，前端開啟既有那份 |
| 解鎖嘗試過多 | 429，提示稍後再試 |

## 測試

沿用 vitest（node 環境）。可獨立測試的純函式：

| 測試 | 驗證 |
| --- | --- |
| 公告過濾與排序 | 以「今天」過濾 `show_until`；`event_date` 優先排序；時區以 America/Los_Angeles 計 |
| 小卡關閉 | 關閉後同一批公告不再顯示；新增一則公告後重新出現；到期減少不會讓它重新出現 |
| 週報通行證 | 簽發後可驗證；過期失效；改密碼（金鑰改變）後失效；竄改值失效 |
| 週次 | 任意日期換算當週週日 |
| 快照 | `announcements` 隨 `rebuildSnapshots` 寫入；舊快照缺欄位時為空陣列 |

另以本機 wrangler + Playwright 驗證：未解鎖時週報 API 全部 401、附件無法直接下載；解鎖後可讀；首頁過期公告不顯示；公告小卡在桌面與手機都不遮住 Hero 主標題與按鈕，× 關閉後重新整理仍隱藏。

## 不做的事

- 電子郵件或推播通知
- 留言、已讀回條
- 排程發佈
- 公告專屬圖片欄位（富文字內可插圖即可）
