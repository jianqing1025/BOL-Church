# Finance：全局搜尋、憑證裁剪旋轉、明細列印

日期：2026-08-17

三項獨立功能，共用既有元件與樣式慣例。

## 一、全局搜尋框（奉獻記錄、支出管理）

### 放置與版面

搜尋框放在 `Toolbar` 最前面，沿用成員管理同款 `<input>`（`.toolbar input` 已限寬 360px）。

工具列順序：

- 奉獻記錄：`搜尋框 → 目前列表合計 → 記錄奉獻 / 年度下拉`
- 支出管理：`搜尋框 → 目前列表合計 → 待審核 → ⚙設置 / 新增支出 / 年度下拉`

支出管理新增「目前列表合計」（原本沒有），位置緊接搜尋框之後。

### 跨年度語意

兩頁的清單原本先被年度下拉篩選過。搜尋要跨全部年度，因此：

- 搜尋框**有內容**時繞過年度篩選，在全部資料中比對；年度下拉停用並顯示為「全部年度」
- 搜尋框**清空**後回到所選年度
- 「目前列表合計」永遠等於畫面上這份清單的總額；搜尋時即為搜尋結果總額

年度下拉在搜尋期間停用，是為了避免兩個篩選條件互相矛盾、使用者無法判斷看到的是什麼範圍。

### 比對規則

沿用成員管理的做法：把可搜欄位串成一條字串，全轉小寫後 `includes` 模糊比對。

| 頁面 | 比對欄位 |
| --- | --- |
| 奉獻記錄 | 日期、成員顯示名、成員中文名、分類、方式、金額、備註 |
| 支出管理 | 日期、描述、分類、付款人、付款方式、狀態、金額、備註 |

分頁 `resetKey` 加入 query，搜尋條件改變時回到第 1 頁。

## 二、憑證裁剪／旋轉

### 問題

`ZoomableImage` 只接收 `src`，不知道自己屬於哪一筆記錄；三個使用位置的「保存」語意也不同（表單是暫存到送出才寫回，檢視彈窗則要立即寫回）。

### 解法

`ZoomableImage` 新增可選 prop `onSave?: (file: File) => Promise<void>`。有提供才顯示編輯控制項，怎麼存由呼叫端決定。

控制列擴充為：

```
－ 100% ＋ │ ⟲ ⟳ │ 裁剪 │ 還原 │ 保存
```

- **旋轉** ⟲⟳：各轉 90°，CSS transform 即時預覽
- **裁剪**：進入框選模式後在圖上拖曳畫矩形，此時停用拖曳平移
- **還原**：清除旋轉與裁剪，回到原圖
- **保存**：將旋轉＋裁剪套進 canvas，輸出 JPEG（沿用 `compressImage` 的 1024px / 品質 0.85），呼叫 `onSave(file)`。無編輯動作時停用

### 三個接入點

| 位置 | `onSave` 行為 |
| --- | --- |
| 奉獻／支出表單的上傳預覽 | 上傳至 R2，只更新表單 state 的 `receiptUrl`；按表單「保存」才寫進資料庫 |
| 表格「查看憑證」彈窗 | 上傳後直接 `saveOffering` / `saveExpense` 寫回 |
| 支出詳情的三種憑證 | 同上，分別寫回 `receiptUrl` / `invoiceReceiptUrl` / `accountReceiptUrl` |

唯讀角色不傳 `onSave`，控制列維持原本的縮放按鈕。

### 跨域畫布污染

憑證圖存放於 `FILES_URL = https://church-finance.bolccop.org`，與 app 網域不同源。直接把 `<img>` 畫進 canvas 再 `toBlob()` 會因畫布污染拋出 SecurityError——報稅簽名圖已踩過同一個坑並改走同源代理。

做法：新增工具函式，把跨域圖片網址轉為同源的 `/api/files/<key>` 代理路徑，`fetch` 成 blob 後再載入 canvas。不需更動 R2 設定或後端。

### 已知副作用

`/api/upload` 沒有刪除介面，「替換」實際上是寫入新檔並更新記錄欄位，舊圖會留在 R2 成為孤兒。不影響功能，本次不處理。

## 三、明細列印（奉獻記錄、支出管理）

### 入口與流程

`PageTitle` 的 `action` 插槽放「列印」按鈕，點擊開啟預覽彈窗：

- 期間切換：`本週`（預設）／`本月`／`本年`
- iframe 預覽 A4 直式版面
- 底部：`列印`、`下載 PDF`

### 期間定義

以**今天**為準，與年度下拉無關：

- 本週：週日起算至週六
- 本月：當月 1 日至月底
- 本年：當年 1 月 1 日至 12 月 31 日

列印內容**不受搜尋框影響**，永遠是完整期間的資料。

### 版面

- 抬頭：教會中英文名與地址（取自 `settings.taxStatement.textFields`，缺值時用 `CHURCH_INFO` 預設）、表名、期間、列印時間
- 內文按分類分組，組內依日期排序，每組結尾一行小計（筆數＋金額），最後一列總計
  - 奉獻欄位：日期／成員／分類／方式／金額／備註
  - 支出欄位：日期／描述／分類／付款人／方式／狀態／金額／備註
- 頁尾：製表人／覆核人／日期簽名欄
- 緊湊排版：約 10pt 字、細行距、斑馬紋，力求一週資料一頁內

### 輸出

- 列印：iframe `srcDoc` + `contentWindow.print()`，同報稅預覽做法
- PDF：沿用既有 html2canvas + jsPDF 的延遲載入與 A4 分頁邏輯
