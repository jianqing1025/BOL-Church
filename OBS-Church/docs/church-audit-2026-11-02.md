# OBS Church 功能核查与修复

核查日期：2026-11-02。当前桌面版本：33.0.3；右下角恢复固定 2×2 四宫格。原核查基线为 33.0.2。

后续补充：用户选择 YouTube 推流，但明确不接 Google OAuth。已撤除新增的远端自动改名流程，保留推流密钥方式及自动生成／复制标题，在 YouTube Studio 手动粘贴。见 [YouTube 推流说明](youtube-setup.md)。

原实现并非全部完成。本次补上了下列缺漏，并保留工作区原有修改。

## 本次修复

- 自动同步不再只检查本机修改：每分钟也检查云端新版本，能读取其他电脑的修改。
- 同步范围补入教会界面的自动切换、等待时间、画中画默认比例、四路输出布局、字幕蒙版和独立字幕框；默认样式原已随内容同步。
- 网页保存请求串行执行，保留保存途中产生的新修改。发生版本冲突时保留本机草稿，由用户选择云端版或本机版。
- 桌面下载云端文件期间如发生本机编辑，不再用下载结果覆盖新编辑。
- 英文界面新增经文默认使用 KJV；主动选择中文和合本时，译本名、书卷、旧约／新约仍按要求显示中文。
- 锁定后禁用卡片点击、双击编辑、Clear、Black、默认样式修改和 B／F1 黑屏操作；方向键和翻页笔仍可翻页。
- 新增内容优先使用当前场景，支持在选中项之后插入。连续翻页时同步选中原生 Sources 中对应的来源。
- 关闭 Church 布局下的 OBS 场景交换和复制入口，并防止转场结束后的场景交换带动主预览。
- 四个录制／直播选择画面固定为 2×2 四宫格；输出区没有重复的开始推流／录像按钮或投影按钮，右侧 mixer 没有额外标题。
- 画中画两种布局切换时保留默认比例，并提供自定义百分比。
- 原生 Media Source／VLC 来源加入摄像机所在的 Live Video 分组，共用不透明度滤镜。
- 第四屏不再继承主幻灯片的文字框位置；默认始终为下方居中，独立编辑字幕框不修改主画面。较长文字会缩放到字幕区内。
- 当前桌面程序和安装包版本为 33.0.3，打包时检查两者一致；在线服务版本仍为 33.0.2。
- 更新了已经上线的 OBS Online 静态资源和 Worker；保留原有账号、场景和云端文件。

## 验证记录

- TypeScript 类型检查通过，桌面 presenter 和 OBS Online 生产构建通过，Worker 类型检查通过。
- 6 个测试文件、16 项测试通过：分页附件、隐藏视频声音、媒体停止、字幕布局、长文字、云端保存串行与冲突保护等。
- 浏览器检查通过：跨 Scene 翻页、锁定后点击无效但方向键有效、英文默认 KJV、和合本中文名称、出处输入位置、视频 Name 自动更新、插入位置。
- 上线后用指定网页密码登录验证：服务报告版本 33.0.2，读取原有 4 个 Scene，32 个卡片媒体编辑入口及 Template，页面没有运行错误。验证没有修改这些场景。
- 指定账号 API 登录成功，原有云端内容可读取。没有以测试数据覆盖现有 D1 内容。
- Windows `obs-studio` 编译通过；读取生成程序的 FileVersion／ProductVersion 均为 33.0.2。
- 安装包由 `installer/build-installer.ps1 -Version 33.0.2 -SkipBuild` 生成；未在用户机器上覆盖安装。

## 尚需明确或现场验收

- **YouTube 标题**：按用户选择不接 Google OAuth，远端标题在 YouTube Studio 手动粘贴；此项不再等待 Google 客户端配置。
- 本次会话没有提供 computer-use 所需的 `node_repl` 运行接口，因此原生 OBS 的逐按钮桌面操作没有标记为实机通过。
- 未实际启动直播、录制、摄像头或 USB 翻页笔。真实视频／声音采集、推流平台授权和录制文件输出应在现场验收。
- 云端同步的是教会内容和教会布局设置；摄像机设备标识、推流密钥及操作系统设置不在上述同步字段内。
